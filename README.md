# 📊 Vendedores x Faturamento x Devolução x Metas

Dashboard gerencial desenvolvido para acompanhamento de **vendas**, **faturamento**, **devoluções** e **metas comerciais**, permitindo uma visão estratégica e detalhada do desempenho comercial da empresa.

---

## 🚀 Funcionalidades

### ✅ Filtros Dinâmicos

A tela permite realizar consultas utilizando os seguintes filtros:

* 📅 Período inicial e final
* 🏢 Empresa
* 👤 Vendedor
* 👨‍💼 Gerente

---

## 📈 Indicadores Gerais

O dashboard possui cards com indicadores consolidados do período selecionado:

* Faturamento Bruto
* Total de Devoluções
* Faturamento Líquido
* Meta Total
* Margem Média
* Quantidade de Devoluções

## 📋 Resumo por Vendedor

Tabela consolidada contendo:

* Código do vendedor
* Nome
* Faturamento
* Devoluções
* Faturamento Líquido
* Meta
* % Atingido
* Margem %
* CMV
* Custos Fixos
* Gastos Variáveis
* Quantidade de Devoluções

---

## 🔎 Detalhamento do Vendedor

Ao clicar em um vendedor, é possível visualizar informações detalhadas:

### Vendas

* Número único da venda
* Cliente
* Tipo de operação
* Valor
* CMV
* Margem %

### Devoluções

* Detalhamento completo das devoluções realizadas

---

## 🧮 Cálculo de Margem

O sistema realiza cálculo automático de margem, permitindo uma análise mais precisa da rentabilidade das vendas.

---

## 🎯 Objetivo

Facilitar a gestão comercial através de uma visão clara e estratégica dos resultados da equipe de vendas, ajudando na tomada de decisão e acompanhamento de metas.
